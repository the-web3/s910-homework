1.学习 websocket, restapi, grpc, graphql 和 json-rpc 等接口传输入模式以及应用场景
 (1)websocket采用全双工通信：连接建立后，客户端和服务器都能主动发送消息，也能同时收发，不需要客户端反复询问服务器有没有新数据。适用于实时聊天，实时行情，实时监控面板。
 (2)restapi通常通过 HTTP/HTTPS，采用“客户端发送请求 → 服务器返回响应”的交互方式.应用场景主要是按需查询和修改数据，例如用户管理、商品列表、订单提交、后台管理系统，以及第三方数据接口。
 (3)grpc是一种远程过程调用（RPC）框架，让客户端像调用本地函数一样，调用另一台机器上的服务。gRPC 常用于微服务之间通信：例如订单、库存、支付服务相互调用；跨语言系统：例如 Go 服务调用 Java 或 Python 服务。持续数据处理：例如设备数据采集、流式识别和实时计算。
 (4)GraphQL 是一种 API 查询语言和执行规范，核心特点是：客户端可以在服务端定义的接口范围内，明确指定自己需要哪些数据字段
 (5)json-rpc 是一种用 JSON 描述“远程方法调用”的轻量协议。实际应用包括： 区块链节点接口：例如以太坊使用 eth_blockNumber 查询区块高度、eth_getBalance查询余额.
